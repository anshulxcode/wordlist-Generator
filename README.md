Wordlist Generator

A simple Python-based wordlist generator that creates customized password candidates from user-provided information and saves them into a text file.

🚀 Features
Takes name, birthdate, and pet name as input
Generates multiple combinations

Creates uppercase, lowercase, and capitalized variations
Adds common numeric patterns

Removes duplicate entries using Python set
Saves the generated wordlist to wordlist.txt


🛠️ Technologies Used
Python 3
Lists & Sets
Loops
String Methods
File Handling

⚠️ Disclaimer

This project is intended for educational purposes and authorized security testing only. Use generated wordlists only on systems, accounts, or applications that you own or have explicit permission to test.
